Nothing is publicly reachable yet. The chart deliberately owns no ingress: the
only path in is the shared Nginx Proxy Manager container, which is also the
only thing that authenticates. Two steps remain, and NEITHER is chart-owned.

1) cloudflared -- add the hostname to the pi-tunnel release, via Helm:

     helm -n {{ .Release.Namespace }} upgrade pi-tunnel <chart> \
       --reuse-values --set 'ingress[N].hostname={{ trimPrefix "https://" $public }}' \
       --set 'ingress[N].service=http://npm.{{ .Release.Namespace }}.svc.cluster.local:80'

   NEVER `kubectl patch` the pi-tunnel-cloudflared ConfigMap. That ConfigMap
   once carried 10 hand-appended hostnames while Helm knew about 2, and a
   plain `helm upgrade` would have 404'd four public hostnames.

2) Nginx Proxy Manager UI (https://pi-agent-npm.woowtech.io) -> Proxy Hosts ->
   Add Proxy Host:

     Domain Names      : {{ trimPrefix "https://" $public }}
     Scheme            : http
     Forward Hostname  : {{ $fullname }}.{{ .Release.Namespace }}.svc.cluster.local
     Forward Port      : {{ .Values.service.port }}
     Websockets Support: ON      <-- required, OpenDesign streams over WS
     Block Common Exploits: ON
     Access List       : the same basic-auth list the pi-agent hosts use
     SSL               : request/attach a cert as the sibling hosts do

   Nothing in the npm Deployment, Service or NetworkPolicy needs to change.

Security posture, so nobody "fixes" it later:
  * The daemon binds 127.0.0.1:{{ .Values.opendesign.port }} and is unreachable over the pod
    network. OD_API_TOKEN and OD_DISABLE_API_AUTH are both ABSENT, and that is
    correct -- unreachable-by-construction beats any token.
  * OD_ALLOWED_ORIGINS is {{ $public }}. A cross-site request with any other
    Origin is rejected by the daemon.
{{- if .Values.nginx.requireOriginOnMutation }}
  * The sidecar returns 403 for any non-GET/HEAD/OPTIONS request with no
    Origin header. Flip nginx.requireOriginOnMutation to false only for
    non-browser automation, and record why.
{{- else }}
  * WARNING: nginx.requireOriginOnMutation is FALSE. Mutating requests with no
    Origin header reach the daemon and are accepted via its loopback-Host
    branch. You are relying on the NPM Access List alone.
{{- end }}
  * This chart holds no credential. BYOK keys are entered in the browser and
    stay browser-local.
